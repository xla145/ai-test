# AIProbe 页面视觉规范

## 设计方向

面向测试人员的测试控制台，气质准确、沉稳、利落。导航和面板采用石墨灰中性色，钴蓝表示主操作与选中状态；成功、失败和待处理使用独立的语义色。视觉重点是用例进度、脚本阶段及执行结果。

## 本次调整

| 层面 | 调整 |
| --- | --- |
| 间距 | 页面边距 32px，区域间距 24px，紧凑卡片内边距 20px，导航行高 36px |
| 配色 | 集中管理 Ant Design 明暗主题，移除 UI 工作台的蓝紫渐变和发光阴影，执行结果与提醒适配明暗主题 |
| 图标 | 保留 Ant Design 图标集，脚本生成使用代码图标，移除装饰性星光 |
| 文案 | 保留业务说明和操作名称，以项目概览、测试状态和真实执行信息建立层级 |
| 字体 | 页面标题 26px、常规界面 14px、辅助说明 12–13px、关键数据 28–32px；数字使用等宽数字排版 |
| 布局 | 侧栏 240px，顶部栏 56px；窄工作区下概览为两列，UI 浏览器移至步骤区下方 |
| 细节 | 统一按钮、表格、卡片、表单、标签、弹窗和页签；报告详情统计支持换行；最近执行显示通过率 |
| 视觉 | 使用产品自身的阶段数据、通过率和状态色，无额外装饰图片或虚构指标 |
| 动效与操作 | 移除侧栏宽度动画；支持减少动态效果；补充列表焦点与概览执行记录的 Enter / 空格入口 |

## 接口生成页细化

- 五步流程采用紧凑步骤条，详细说明通过悬停和键盘聚焦查看，避免五组长说明同时挤占宽度。
- 两类来源使用独立面板：标题、用途说明、导入选项、生成入口分区排列；工作区小于 960px 时纵向排列。
- 文件入口采用带格式提示的整行操作区；地址导入提供独立标签和说明；业务场景补充的开关与模型用量说明单独成行。
- 概览四步卡片操作区统一为 40px 高的柔和填色按钮，带右侧箭头，生成接口用例为次级操作。
- 补充验证地址模式的输入与空值禁用状态，996px 和 1440px 窗口下接口生成页无横向溢出。

## 维护入口

- `desktop/src/renderer/theme.ts`：Ant Design 配色、组件尺寸与明暗主题
- `desktop/src/renderer/styles.css`：自定义组件颜色变量、布局、字体、响应式与焦点样式
- `desktop/src/renderer/components/PageHeader.tsx`：业务页面标题与描述

新增页面应复用现有主题、PageHeader 和布局类，语义色使用主题 token 或 `--console-success`、`--console-error`、`--console-warning`，避免硬编码仅适合浅色背景的颜色。

- 快速开始保留收起、展开、关闭和步骤跳转；窄窗口的标题操作独立成行，步骤自然换行。
- 数据库连接名称、类型和只读标签允许换行，完整地址可通过提示查看；测试、编辑、删除按钮放在独立操作行。
- 数据库工作区使用响应式网格，工作区小于 960px 时连接列表和查询区上下排列；查询区的快捷键说明、连接选择、JSON 参数及执行按钮分区呈现。
- 浏览器演示模式验证 996px 窗口的工作流页面和数据库页无横向溢出，并检查深色主题；验证快速开始收起、展开、步骤跳转，以及数据库演示查询和连接测试。
- 本轮生产构建与 104 项桌面测试通过。全量类型检查被并行接口工作区开发阻塞：`mock.ts` 尚未实现 `AitestApi` 新增的接口方法（如 `listApiDefinitions`、`previewApiImport`）。

## 导航开关位置调整

- 将展开/收起开关移至顶部栏项目路径左侧，使用 32px 图标按钮，保留悬停提示、键盘操作与展开状态语义。
- 设置页与无项目状态也保留顶部栏，避免收起后丢失入口；窄窗口隐藏顶部辅助标签，为项目路径留出空间。
- 浏览器验证展开、收起和设置页入口，渲染端类型检查通过。

## 统一窗口工具栏与侧栏轴线

- 顶部工具栏从内容列移至整个窗口顶部，固定高 52px；侧栏与业务内容位于下方，展开和收起不再改变开关的位置。
- 侧栏菜单图标与项目切换图标统一为 16px，中心位于距窗口左侧 32px；品牌图形共用该中心轴线。品牌、项目名称与菜单文字从 52px 起排。
- macOS 使用 Electron 原生 hiddenInset 标题栏与真实窗口控制按钮，顶部为按钮预留 100px；空白区域可拖动，按钮与项目路径禁用拖动。Windows/Linux 保留原生窗口边框，浏览器不显示模拟窗口按钮。
- 主进程与渲染端类型检查、渲染端构建通过；桌面测试 116 项通过、1 项失败，失败为未在本轮修改的 explore-prompt.test.ts 对提示词的旧断言，与当前 prompts.ts 的文案不一致；696px 浏览器预览验证顶部与内容尺寸、无页面横向溢出，以及键盘收起和点击展开。
- 原生标题栏需要重新创建 Electron 窗口后生效。本轮未启动新的 Electron 实例，macOS 原生按钮与拖动行为仍需桌面端实测。
