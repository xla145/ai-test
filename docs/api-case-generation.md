# 单接口参数用例生成

在「接口测试 → 单接口测试」选择已导入的接口，调整当前请求参数，点击「根据参数生成用例」。生成基于 OpenAPI 参数约束，使用 Schemathesis 4.33.4，无需配置大模型。

## 使用流程

1. 先确保当前基础请求可正常调用，真实业务 ID 可以沿用当前填写的值。
2. 设置生成上限（1–100，默认 30）和随机种子。相同请求、约束、依赖版本及种子可以复现同一组用例。
3. 选择响应断言方式。普通接口按 HTTP 状态码检查；HTTP 200 包装业务错误的接口，应选择业务码模式，并明确填写成功业务码和参数错误业务码。
4. 生成预览，展开检查请求参数和断言，勾选需要的用例，保存为草稿。
5. 保存后可在关联单接口用例中继续编辑、试跑和审核；审核后进入现有脚本回归流程。

生成不发送 HTTP 请求，不调用模型，也不自动执行数据库准备或校验。环境 token 和角色选择继续使用现有运行时注入方式；内联 Authorization 等鉴权头不会复制到生成用例中。

## 覆盖内容

- 当前基础参数、必填缺失、可选参数省略、缺少请求体。
- Query、路径、Header 与 JSON Body 参数；JSON 对象中的嵌套字段。
- 空值、空字符串、错误类型、合法与非法枚举。
- 数值、字符串长度与数组元素数量边界。
- Schemathesis 生成的 Schema 正反例，覆盖正则、格式及复杂 Schema。

按实际 HTTP 序列化判断参数是否合法，避免把序列化后仍合法的 Query 字符串误当作反例。单次数量有上限，达到上限会提示；不声称已穷尽所有输入或约束。复杂约束不能生成时会提示具体字段，并保留可用规则用例。

## 保存与兼容

- 预览不会写入用例库；保存时根据相同输入重新生成并校验勾选项。
- 去重依据接口与生成请求内容，重复保存会跳过已存在的用例，不覆盖人工编辑或已审核用例。
- 接口定义版本变化后，需要先确认新版本再生成。
- 仅支持当前执行器能执行的 JSON 请求体；外部 Schema 引用需先内联，生成阶段不访问外部引用。
- 真实资源是否存在、跨字段业务规则、接口的业务错误码仍需要明确配置和人工检查。

引擎运行环境要求 Python 3.11+。开发环境运行 `npm run prepare:engine -w desktop` 准备依赖；自定义解释器应安装 `engine/pyproject.toml` 中的依赖。安装包构建也会携带 Schemathesis，日常执行已保存的用例不需要重新生成。
