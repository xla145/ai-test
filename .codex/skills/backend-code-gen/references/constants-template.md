# 枚举与字典

先查目标模块 `domain/enums` 和系统字典。可由运营维护的值优先沿用系统字典；固定业务状态、合法转换及代码分支使用业务枚举。技术常量按已有 constants 布局，不为每个业务生成 Constants 大类。

- 枚举 code 的 Java 类型和数据库值保持一致，不能用 ordinal 持久化。
- 解析未知值返回明确业务错误；不要默默使用第一个枚举或默认状态。
- BO 可先接收 code，再通过枚举解析/校验；不要依赖 Jackson 默认枚举名称破坏既有接口。
- 下拉复用现有 code/label VO；只有用户要求时添加接口。
- 业务枚举放在所属模块；跨域通过公开契约交互，不将所有枚举移入 common。
- 错误文案沿用 ServiceException 或既有错误码机制，不照搬旧项目 Result 消息常量。
