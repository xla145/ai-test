# 正确性与常见故障

| 症状/风险 | 检查与处理 |
|---|---|
| 新模块编译但接口 404 | 聚合不等于运行依赖；查启动 dependencies、扫描与路由 |
| 有权限注解仍可修改他人记录 | 权限码只控制操作；查租户/所属者/数据权限条件 |
| 继承 TenantEntity 仍串租户 | 查 tenant.enable、excludes、原生 SQL、上下文和异步传播 |
| BO 可覆盖系统字段 | 查 BaseEntity 继承字段和 Mapstruct 映射；限制可写字段，审计用可信填充 |
| ID 在前端精度丢失 | 核对 Jackson Long 字符串序列化及实际 JSON，不依赖 JS Number |
| 已删除记录仍能修改 | 查 @TableLogic、删除配置、自定义 SQL 和有效记录条件 |
| 字段无法清空或误清空 | 定义未传/null 语义；使用局部更新策略，不改全局非空策略 |
| 并发产生重复数据 | 数据库唯一约束兜底，范围与租户/软删除规则一致 |
| 状态被覆盖 | 更新限制原状态/版本和归属，检查影响行数；先查后改不足以防并发 |
| 子表失败但主表提交 | 查事务代理/自调用/传播/吞异常；Mock 测试不能证明回滚 |
| 外部消息已发但事务回滚 | 按既有提交后事件/可靠投递或补偿方案实现 |
| 分页出现 N+1 | 收集主表 ID 批量查询关联；空集合跳过查询 |
| 声称批量实际逐条 insert | 使用当前可用批量 Mapper/持久化能力并核实执行方式 |
| 子表删后插丢失历史 | 明确可替换附属关系；有引用/审计则差异更新 |
| 任意文件 ID 可绑定 | 校验有效性、租户/所属者和访问范围，解绑不默认删文件 |
| SQL/内部异常直接返回 | 沿用全局异常处理，业务错误与系统错误分开 |
| 启动成功但缺表缺字段 | 查 Flyway 日志及有效迁移位置，不能据启动成功判断迁移成功 |

只对当前业务实际存在的风险补实现与验证，不扩大任务。模板结构、示例字段和路径需适配，不能把省略代码、空校验或 TODO 当成完成产物。
