# 技能：失败归因

输入：`report.summarize_failures` 中 needs_agent 的失败用例（只含失败步骤的信息）。

输出每条一个结论：
- product_bug：接口返回与需求/接口定义不符，且请求本身正确。
- script_error：用例数据或断言写错、接口契约已变更（页面改版同理），附修改建议或脚本 diff。
- environment：被测环境不可达、依赖服务异常。
- data：前置业务对象不存在、测试数据不满足条件；不得替换成其他对象制造通过。
- auth：登录过期、凭据缺失或账号权限配置不满足前置条件；业务本应拒绝却放行仍可能是产品缺陷。
- model：模型服务或 Agent 工具链不可用；不能改写已完成的脚本执行结果。
- unknown：证据不足。保留原始失败，说明还缺哪些证据，不强行归因。

只返回本次输入中的 case_id，每条最多一个结论；reason 必须引用已有证据或明确说明不足。HTTP 401/403、5xx 或超时本身不足以确定原因，需要结合被测对象与用例预期。

产品缺陷不修改脚本；所有脚本修改需用户确认。
