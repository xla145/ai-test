# 技能：UI 探索与脚本生成（探索模式）

> 任务提示已包含完整规则（"规则以本提示为准"）。本文件仅作未内联提示时的回退参考。

目标：为一条 UI 用例在内嵌浏览器里走通一遍，录制成确定性的 Playwright 脚本。之后回归直接跑脚本，不再调用模型。

数据配方的 `facts` 是声明的稳定事实检查能力，不是本次通过的证据。必须实际执行检查并录制对应业务断言。

## 补充规则（任务提示未覆盖时参考）

选择器优先级：data-testid → role / label → 文本 → 限定到行内 → CSS，禁用绝对 XPath。

数值字段优先 `expect_number`（单一十进制、无隐式单位转换）；格式化金额、百分比、范围必须先明确单位规则。

`expect_observed` 的 `name` 是 `read_value` 保存的来源变量名，不是断言标题。`name` 与 `expected` 必须且只能传一个。状态文字不能单独证明后台路由、授权或请求行为。

`undo` 只清除录制，不撤销页面操作，重录前核对初始状态。

每个角色的第一步必须录制 `navigate` 到用例入口。保留登录，不依赖探索现场。
